# Coalesce

中国电信 Logo 的粒子动画。画面上的每个小点，都是从 Logo 图片里采出来的，最后会回到自己在 Logo 上的位置。

## 页面

| 文件 | 效果 |
| --- | --- |
| `index.html` | 粒子先聚成 Logo，停一下，再炸开，然后收回。只播放一次。 |
| `index2.html` | 粒子从画面左侧飞入，在屏幕右侧收成 Logo。 |

## 怎么看

不要直接双击 HTML 文件。浏览器会把本地图片当成跨域资源，读不到像素，动画就出不来。

在项目目录里启动一个本地服务器：

```bash
python3 -m http.server 8731
```

然后在浏览器打开：

- 粒子汇聚：http://127.0.0.1:8731/
- 从左飞入：http://127.0.0.1:8731/index2.html

看完后在终端按 `Ctrl + C` 关掉服务器。

## 文件

```text
index.html          汇聚、炸开、收回
index2.html         从左侧飞入
images/telecom.png  Logo 原图
```

Logo 在画面上显示为原图的三分之一。采样时会跳过右下角的水印。
